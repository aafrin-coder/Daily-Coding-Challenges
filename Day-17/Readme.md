# Day 17

# 1 Is Subsequence

- **Difficulty:** Easy
- **Language:** Java

## Approach
- Use the Two Pointers technique.
- Traverse both strings together.
- If characters match, move both pointers.
- Otherwise, move only the pointer of the second string.
- If all characters of `s` are matched, return `true`.

## Complexity
- **Time:** O(n)
- **Space:** O(1)

# 2 Maximum 69 Number

- **Difficulty:** Easy
- **Language:** Java

## Approach
- Convert the number into a character array.
- Find the first occurrence of `'6'`.
- Change it to `'9'` and stop.
- Convert the array back to an integer.

## Complexity
- **Time:** O(n)
- **Space:** O(n)
