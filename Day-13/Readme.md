# Day 13

## Problem 1

**Name:** Valid Palindrome

- Platform: LeetCode
- Difficulty: Easy
- Language: Java
- Approach: Remove all non-alphanumeric characters and convert the string to lowercase. Use two pointers from the beginning and end of the string to compare characters. If all matching characters are equal, the string is a valid palindrome.
- Time Complexity: O(n)
- Space Complexity: O(n)

## Problem 2

**Name:** Convert a Number to Hexadecimal

- Platform: LeetCode
- Difficulty: Easy
- Language: Java
- Approach: Use Java's built-in `Integer.toHexString()` method to directly convert the given integer into its hexadecimal string representation.
- Time Complexity: O(1)
- Space Complexity: O(1)
