
# Problem 1
# Complement of Base 10 Integer

- **Difficulty:** Easy
- **Language:** Java

## Approach
- Handle special cases (`0` and `1`).
- Traverse the binary representation of the number.
- Flip each bit and construct the complement.

## Complexity
- **Time:** O(log n)
- **Space:** O(1)


# Problem 2

# Mirror Distance of an Integer

- **Difficulty:** Easy
- **Language:** Java

## Approach
- Reverse the given integer.
- Find the absolute difference between the original and reversed number.

## Complexity
- **Time:** O(log n)
- **Space:** O(1)
