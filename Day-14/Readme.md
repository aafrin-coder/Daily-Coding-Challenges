# Day 14

## Problem 1

**Name:** Largest Time for Given Digits

- Platform: LeetCode
- Difficulty: Medium
- Language: Java
- Approach: Check all possible valid times from 23:59 to 00:00. Compare the digits of each time with the given digits after sorting. Return the first valid time found.
- Time Complexity: O(1)
- Space Complexity: O(1)

## Problem 2

**Name:** Maximum Number of Balloons

- Platform: LeetCode
- Difficulty: Easy
- Language: Java
- Approach: Count the frequency of the required characters ('b', 'a', 'l', 'o', 'n') and return the minimum possible number of times the word "balloon" can be formed.
- Time Complexity: O(n)
- Space Complexity: O(1)
